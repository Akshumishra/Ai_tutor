# Quiz API

Base path: `/api/quiz`  
**File:** `backend/src/backend/api/quiz.py`

The Quiz API handles chapter-level end-of-chapter quiz generation and submission.

---

## Overview

The AI Tutor has two quiz mechanisms:

| Quiz Type | Triggered By | Agent |
|-----------|-------------|-------|
| **Per-outline quiz** | Teacher Agent via `create_quiz` tool | TeacherAgent (inline) |
| **End-chapter quiz** | Frontend "End Chapter Quiz" button | QuizAgent via `/api/quiz/generate` |

This API covers the **end-chapter quiz only**.

---

## Endpoints

### `POST /api/quiz/generate`

Generates a multiple-choice quiz for an entire chapter based on its outline.

**Request:**
```json
{"chapter_id": "uuid-of-chapter"}
```

**Response (200):**
```json
{
  "chapter_id":    "uuid",
  "chapter_title": "Introduction to Python",
  "questions": [
    {
      "question": "What is Python primarily used for?",
      "options": [
        "Web development only",
        "General-purpose programming",
        "Database management",
        "Hardware control"
      ],
      "correct": 1,
      "explanation": "Python is a general-purpose language used in web dev, data science, AI, and more."
    }
  ]
}
```

**Question object schema:**

| Field | Type | Description |
|-------|------|-------------|
| `question` | `string` | The quiz question text |
| `options` | `string[]` | 4 answer choices |
| `correct` | `int` | 0-indexed correct answer index |
| `explanation` | `string` | Explanation of the correct answer |

| Code | Condition |
|------|-----------|
| 200 | Questions returned |
| 400 | Invalid chapter UUID |
| 404 | Chapter not found |
| 500 | LLM parsing failure |

---

### `POST /api/quiz/submit`

Submits user answers, calculates score, and marks the chapter as **completed** if score ≥ 70%.

**Request:**
```json
{
  "chapter_id": "uuid-of-chapter",
  "answers":    [1, 0, 2, 3],
  "questions": [
    {
      "question": "...",
      "options":  ["..."],
      "correct":  1,
      "explanation": "..."
    }
  ]
}
```

!!! note
    The `questions` array must match the one returned by `/quiz/generate` — the backend uses the `correct` field from this payload for grading.

**Response (200):**
```json
{
  "score":         75,
  "passed":        true,
  "correct_count": 3,
  "total":         4,
  "results": [
    {
      "question":   "What is Python primarily used for?",
      "selected":   1,
      "correct":    1,
      "is_correct": true
    }
  ]
}
```

**Grading logic:**

```python
score  = int((correct_count / total) * 100)
passed = score >= 70
if passed:
    chapter.status = Status.COMPLETED
```

| Code | Condition |
|------|-----------|
| 200 | Graded result returned |
| 400 | Answer count ≠ question count |
| 400 | Invalid chapter UUID |
| 404 | Chapter not found |

## QuizAgent

The quiz is generated by `src/llm/quiz_agent/agent.py` using the `invoke()` method (synchronous, no streaming):

```python
agent = QuizAgent(chapter_id=str(chapter_uuid), mode="summary", outline=chapter.outline)
raw, _ = agent.invoke()
questions = json.loads(raw)
```

The agent is prompted to return **only valid JSON** (an array of question objects). The API strips any markdown code fences before parsing.

---

## Pass/Fail Threshold

| Score | Result |
|-------|--------|
| ≥ 70% | Chapter marked `completed`, next chapter unlocked |
| < 70% | Chapter remains `in_progress`, learner must retry |

The pass threshold of **70%** is hardcoded in `quiz.py` and can be adjusted there.
