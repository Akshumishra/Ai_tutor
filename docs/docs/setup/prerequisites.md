# Prerequisites

Ensure the following are installed before setting up AI Tutor:

## 1. Required Software
- **Python 3.11+**
- **Node.js 18+** (includes npm)
- **PostgreSQL 15+**
- **Redis 7+**
- **Git**

## 2. API Keys
You will need to generate the following keys to configure your environment:

- **OpenAI API Key**: For the AI agents ([platform.openai.com](https://platform.openai.com/api-keys))
- **Tavily API Key**: For deep research ([app.tavily.com](https://app.tavily.com))
- **Google OAuth Client ID**: For Google Login (Create a Web app client in [Google Cloud Console](https://console.cloud.google.com/))
- **Gmail App Password**: For sending OTPs (Enable 2FA and generate an App Password in your Google Account Security settings)
